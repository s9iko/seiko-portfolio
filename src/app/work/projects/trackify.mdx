## Overview

Trackify is a full-stack project management platform built for engineering teams to centralize project tracking, scheduling, tasks, workloads, and reporting. Developed through iterative feedback, the system was successfully deployed for internal use.

## Key Features

* **Project Management**: Create, assign, track, and manage projects throughout their lifecycle.
* **Interactive Gantt Timeline**: Visualize project schedules, deadlines, extensions, and workloads.
* **Task Management**: Organize project tasks with drag-and-drop reordering.
* **Project Notes**: Create multi-page project notes with image support.
* **Role-Based Access**: Separate Admin and Engineer permissions and workflows.
* **Dashboard & Reports**: Monitor deadlines, workloads, project status, and generate reports.
* **Notifications & History**: Track important project updates, status changes, assignments, and extensions.

## Technologies Used

* **Frontend**: Next.js, React.js, TypeScript
* **Backend**: Node.js, Express.js
* **Database**: PostgreSQL
* **ORM**: Prisma
* **Deployment**: PM2, Internal Windows Server
* **Version Control**: Git, GitHub


## Outcome

Successfully developed and deployed Trackify as an internal engineering project management platform, providing a centralized way to manage projects, timelines, tasks, workloads, and reporting.
